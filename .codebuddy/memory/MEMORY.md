# 长期记忆

## 项目: QT (PyQt6 电子工具软件)

- 主程序 `test1.py`，左侧导航页面模块化，每个工具一个 `*_page.py`（类名 `XxxPage`），占位页用 `PlaceholderPage`。
- 页面风格：卡片式（`QFrame#card` + 圆角），主色 #409EFF，结果格子用浅灰底 #F5F7FA。
- 功率变换页 `power_conversion_page.py`：LDO 降压计算，实时计算（textChanged 直连），固定型号 Vout 锁定仅"自定义"可编辑，输入错误温和提示不弹窗。

## 用户偏好

- **器件选型贴片封装优先**（2026-08-20）：LDO 型号库默认先展示 SOT-223/SOT-89/SOT-23 贴片系列，直插仅作参考。
- **型号库封装必须核实真实规格**（2026-08-21 用户两次纠错）：78L05/78L08 贴片封装为 SOT-89（无 SOT-223）；SOT-223 是 AMS1117/LM1117 等 1A LDO 的封装；78L05 直插为 TO-92。写入器件库前应先与用户确认或查 datasheet。
- 工具计算要实时（无需点按钮）。
