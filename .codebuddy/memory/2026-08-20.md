# 2026-08-20

## 功率变换页面开发
- 项目 `QT/` 为 PyQt6 电子工具软件，主程序 `test1.py`，左侧导航含"功率变换"页。
- 新建 `power_conversion_page.py`（类 `PowerConversionPage`），替换 `test1.py` 中原占位页 `PlaceholderPage("功率变换")`，并新增 import。
- 功能：LDO（如 78L05）降压电路计算——串联电阻 R=(Vin−Vout−Vdrop)/I、电阻功率、LDO 功耗 P=Vdrop×I、温升 ΔT=P×RθJA、结温 Tj、效率；内置型号库（78L05/7805/78L12/LM1117/AMS1117 等）自动填充参数；E24 标准阻值推荐；过流/过热警告。
- 核心公式已用 Vin=12V、Vout=5V、Vdrop=2V、I=100mA 验证：R=50Ω、P_R=0.5W、P_LDO=0.2W、ΔT=40°C、Tj=65°C。
- 用户反馈修改：固定型号（如 78L05）选中后 Vout 输入框锁定不可修改（置灰+tooltip），仅"自定义"型号可编辑 Vout。
- 用户反馈修改2：改为实时计算——输入框 textChanged 直连 calculate，移除"开始计算"按钮；输入错误不弹窗，改为警告区温和提示；calculate 加 hasattr(result_r) 保护（结果面板未创建时跳过）。
- 用户检查温升公式：核心公式 ΔT=P×RθJA、Tj=Ta+ΔT 正确；补充了静态电流 Iq 项（型号库增加 iq 字段，新增 Iq 输入框），功耗公式改为 P=Vdrop×I+(Vout+Vdrop)×Iq。78L05 例：P=242mW、ΔT=48.4°C、Tj=73.4°C（原 65°C）。
- 型号库更新（贴片优先，2026-08-21 用户最终确认封装）：贴片区 78L05 (SOT-89)、78L08 (SOT-89)、AMS1117-3.3/5.0 (SOT-223)、HT7533/7550 (SOT-89)、XC6206 (SOT-23)、ME6211/LP5907/RT9013/MIC5205 (SOT-23-5)；直插区 78L05/78L33 (TO-92)、7805/7808/7812 (TO-220)。电路示意图用通用 LDO 标识。
- **封装纠错教训：78Lxx 系列贴片封装是 SOT-89，无 SOT-223**（SOT-223 是 AMS1117/LM1117 等 1A 稳压器的封装）。
- 电流降额需求（用户要求）：芯片至少 80% 降额使用。新增"降额系数%"输入框（默认80），警告区判断：负载>绝对最大电流→严重过流禁用；负载>降额限值(imax×derate)→提示该芯片不可用并推荐替代型号（suggest_bigger_regulator 优先同电压更大电流）；合格则提示占用百分比。例：78L05 100mA + 100mA 负载 + 80% 降额 → 需换 ≥125mA 芯片（推荐 MIC5205-5.0）。
- 参数持久化（用户要求）：环温/热阻/静态电流等支持保存为默认。用 QSettings("QT_Tools","PowerConversion")，新增"💾 保存为默认"和"↺ 恢复默认"按钮；保存字段：型号索引、Vin、负载电流、降额系数、环温、热阻、Iq；initUI 末尾 load_defaults()（先切型号再覆盖保存值），恢复出厂则 clear() + 重置。已验证读写正常。
- **Bug修复：恢复默认后不刷新**——QLineEdit.setText 在文本未变化时不发 textChanged，导致 calculate 不触发。修复：restore_factory_defaults 末尾强制 self.calculate()。
- UI调整（用户要求）：删除页面顶部"⚡ 功率变换计算工具"标题；保存/恢复默认的操作提示改到页面底部独立 op_msg_label（show_op_message），不再挤占右侧警告区，右侧只显示计算/降额/结温警告。
- 单位补充（用户要求）：输入框标签全部带单位（Vin (V)、Vout (V)、最小压降 (V)、负载电流 (mA)、降额系数 (%)、环境温度 (°C)、热阻 (°C/W)、静态电流 (mA)）；结果标题带单位（R (Ω)、功耗 (W)、压降 (V)、ΔT (°C)、结温 (°C)、效率 (%)）；计算说明公式也标注单位。
