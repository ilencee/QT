## 功率变换页：电阻选型方案增强（封装+成本+PCB空间+并联替代）

- 用户需求："电阻推荐不光推荐功率, 还要推荐封装, 考虑价格和 PCB 空间, 比如 2512 是否可以用 4 个 1206 替代"。
- 新增类属性：
  - `PACKAGES`：封装参数表（额定功率 W / 相对单价 / 相对 PCB 面积，以 0603=1.0 为基准）：0603(0.1W/1.0/1.0)、0805(0.125/1.3/1.8)、1206(0.25/1.6/3.2)、2512(1W/4.5/7.5)、大功率贴片(2W/12/16)、插件绕线(5W/6/22)。
  - `PARALLEL_PACKAGES = ("1206","0805","0603")` 可并联替代的小封装序列。
- 新增 `suggest_resistor_plan(p_r)`：
  - p_need = p_r×2（2 倍余量）→ rating → 单颗方案 `1×{pkg} ({rating}W)`。
  - 遍历小封装，计算并联颗数 n = ceil(p_need/额定)，仅 2~8 颗合理；按 (成本, 面积) 元组选最优并联方案。
  - 对比单颗 vs 并联的 cost/area，输出标签：更便宜更省空间 / 更便宜 / 更省空间 / 成本空间略增。
  - 返回 `"1×2512 (1W) | 替代 4×1206 并联, 每颗 0.25W (成本/空间略增)"` 形式。
- 结果格子"电阻功率 (W)"文本改为 `"{功率} (需 ≥{rating}W)\n{plan}"`（富文本换行显示）。
- 数值验证（独立脚本）：0.05W→1×0603；0.5W→1×2512 或 4×1206 并联（成本/空间略增）；1W→大功率贴片或 8×1206；1.5W+→插件绕线（并联超 8 颗不再建议）。
- 编译、lint 通过。
